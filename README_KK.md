# GAME HUB PROJECT AUDITOR

**Студенттік ойын жобаларын автоматты бағалау платформасы**

Оқу орынының оқытушысына арналған жүйе: студенттердің «Қазақстан тарихы — GAME HUB» жобаларын нақты браузер арқылы автоматты тексеріп, **100 ұпайлық** жүйе бойынша дәлелдерге негізделген баға береді. Барлық интерфейс **қазақ тілінде**.

Бастапқы құжат: `CYB26-1.2.3.4 Project Time.pdf` (6 техникалық тапсырма + ортақ міндетті жүйе). Талаптар матрицасы сол PDF-тен өзгертілмей алынған — қараңыз: [`docs/TALAPTAR_MATRITSASY.md`](docs/TALAPTAR_MATRITSASY.md).

## Мүмкіндіктері

- **Нақты браузерлік тестілеу** (сервер жағындағы Playwright + Chromium): сайт қолжетімділігі, интерфейс, ойын механикасы, тапсырма профильдері (6 жанрға бөлек), адаптивтілік (390×844, 768×1024, 1366×768), қауіпсіздік.
- **6 тапсырма профилі**: A1 Action/Arcade/Survival, A2 Strategy/Tower Defense, A3 Shooter/Quiz, A4 Racing/Quiz, A5 Match-3/Puzzle/RPG, A6 Adventure/Escape Room + барлығына ортақ талаптар (Google кіру, 6 тапсырма түрі, «жан біткенде» механикасы, GAME HUB порталы, қиындық жүйесі, киберқауіпсіздік).
- **Детерминистік бағалау қозғалтқышы**: 9 критерий (20+15+15+15+10+10+5+5+5 = 100). Бірдей дәлел + бірдей рубрика = бірдей ұпай. Тексерілмеген талаптарға ұпай берілмейді де, нөл де қойылмайды.
- **Дәлел жинау**: әр тестке скриншот, орындалған әрекеттер, күтілетін/нақты нәтиже, шектеулер.
- **Расталған / алдын ала баға** ажыратылады; тексеру жабылымы мен дәлел сенімділігі көрсетіледі.
- **PDF (қазақша Unicode) және CSV экспорт**.
- **SSRF қорғанысы**: тек http/https; localhost, жеке IP, бұлт метадеректері бұғатталады; әр редирект қайта тексеріледі; сұраныстар саны, таймауттар шектелген; браузер оқшауланған контексте жұмыс істейді.
- **Рубриканы баптау**: салмақтар мен шектерді өзгерту; әр тексеру өз рубрика нұсқасын сақтайды.

## Жылдам бастау (жергілікті)

```bash
npm install
npx playwright install chromium --with-deps   # браузер ортасы
cp .env.example .env                          # ADMIN_TOKEN мәнін өзгертіңіз!
npm run build -w client                       # клиент құрастыру
npm run start -w server                       # http://localhost:8787
```

Жүйеге кіру: `.env` файлындағы `ADMIN_TOKEN` мәні.

Сынақ сайты (fixture): `ALLOW_LOCALHOST_FOR_TESTS=1` болғанда `http://localhost:8787/fixture/` мекенжайында қолжетімді. **Бұл — студент жобасы емес**, платформаның өзін тексеруге арналған басқарылатын сайт (жұмыс істейтін және әдейі бұзылған мүмкіндіктері бар).

## Тестілерді іске қосу

```bash
npm run test:unit          # 46 бірлік тесті (ұпай қозғалтқышы, SSRF, CSV, матрица)
npm run test:integration   # толық құбыр: сервер + нақты браузер + fixture
npm run test:e2e           # Playwright: қазақша UI + толық пайдаланушы ағыны
npm run typecheck          # TypeScript тексеруі (shared, server, client)
```

## Жоба құрылымы

```
shared/      — ортақ код: типтер, қазақша сөздік (i18n), 6 тапсырманың талаптар
               матрицасы, рубрика, детерминистік бағалау қозғалтқышы, SSRF тексерулері, CSV
server/      — Express + Playwright сервері: тапсырмалар кезегі, браузерлік тест
               профильдері, дәлел жинау, PDF/CSV есептер, JSON-дерекқор (Firebase опциясы)
client/      — React + TypeScript + Vite + Tailwind (толығымен қазақша UI, 9 бөлім)
fixtures/    — басқарылатын сынақ сайты (fixture)
tests/       — unit / integration / e2e тестілер
docs/        — орналастыру нұсқаулығы, талаптар матрицасы, финалдық есеп
data/        — дерекқор, есептер, скриншот-дәлелдер (жұмыс уақытында жасалады)
```

## Қауіпсіздік ескертулері

- Өндірісте `ALLOW_LOCALHOST_FOR_TESTS=0` болуы **міндетті**.
- `ADMIN_TOKEN` — күшті кездейсоқ мән; оны ешқашан репозиторийге қоспаңыз.
- Аудитор URL-дерді сенімсіз кіріс деп санайды: DNS шешімі тексеріледі, редиректтер қайта сүзіледі, бет ішіндегі сұраныстар ішкі мекенжайларға жіберілмейді.
- Скриншоттар мен есептер авторизациясыз берілмейді; құпияға ұқсас жолдар есептерден жасырылады.

Толық нұсқаулық: [`docs/DEPLOY_KK.md`](docs/DEPLOY_KK.md).
